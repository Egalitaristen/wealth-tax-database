Build a database for your country or region

Each country is a folder of plain CSV files in data/<iso2>/. A GitHub Action rebuilds this site whenever a pull request is merged, so a new folder becomes a shaded country on the world map.

  1. Fork the repository and read CONTRIBUTING.md.
  2. Follow the workflow in skill/SKILL.md, by hand or with an AI assistant. Start with the most prominent supporters in every layer, then plan the next runs. Local sweeps are sampled first. The skill covers where to look, how to grade evidence and how to record sources.
  3. Create data/<iso2>/ with python skill/scripts/wtdb.py init, add a meta.json, and fill the tables.
  4. Validate with python skill/scripts/wtdb.py validate data/<iso2>. The same check runs on your pull request.
  5. Open a pull request. New rows start as unverified; a second person confirms them.

Optional: add a boundaries.json of your sub-national units to get a local map like the UK one.

Rules that apply everywhere

  • Supporters only. Opponents and sceptics are not listed.
  • Public figures and organisations, with a dated source and a short quote.
  • Petition signers and other private individuals are never recorded.
  • People are assumed alive unless a death record is found; those people are removed.
