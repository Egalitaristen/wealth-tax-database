## What the licence does not cover

- **Quotes** in the `quote_original` column are short extracts from the cited sources. They remain under the copyright of their publishers and are included for attribution and verification.
- **Boundary files** (`boundaries.json`) keep the licence of their source, named inside each file. The UK file uses ONS data under the Open Government Licence v3.0 (contains OS data © Crown copyright and database right). The Swedish file uses Statistics Sweden's (SCB) digital boundaries, released under CC0. The US file uses US Census Bureau cartographic boundaries (public domain) via the us-atlas package. The German file uses © GeoBasis-DE / BKG (2025), VG2500, under the Datenlizenz Deutschland – Namensnennung – Version 2.0. The Indian file is a simplified copy of district and state shapes compiled by udit-001 (india-maps-data on GitHub) from public sources; the compiler states no licence, so treat the shapes as provisional and replace them with an official source before wider reuse. The site prints each file's source on the country's Method page.
- **World outlines** in `site/vendor/` come from the `world-atlas` package (Natural Earth, public domain).
